<b>Path To Varsity</b><br>
Video link : https://youtu.be/sV2tnjpxIuI<br>
<p>The purpose of this project is to design and implement a connected sequence of six animated 2D 
and 3D scenes that together tell the story of a single day in a DIU student's life.
Each scene is implemented as an 
independent C++/GLUT program that reuses the same core computer-graphics principles -- 
primitive drawing, geometric transformations, timer-driven animation, and (in most scenes) real
time keyboard/mouse interaction and WinMM-based sound.</p>

<P>The project culminates in a complete narrative arc following a DIU student's day, featuring: <br>
• A morning wake-up sequence with a timeline-driven character pose transition and an 
interactive alarm clock (Scene 1) <br>
• A street-level commute scene with traffic, pedestrians, and synchronized ambient sound 
(Scene 2) <br>
• A parallax-scrolling bus journey across a river and bridge into the city (Scene 3) <br>
• Arrival at the DIU campus with a crowd of independently phased walking students (Scene 4) <br>
• An elevator ride modeled as an explicit door-close/ascend/floor-update/door-open state 
machine (Scene 5) <br>
• A fully lit, camera-controlled 3D classroom built from cuboid, cylinder, and sphere primitives 
(Scene 6) <br>
Ultimately, the project serves as a bridge between everyday student experience and rigorous 
technical application, meeting all academic requirements for 2D and 3D transformations, 
rasterization principles, and real-time rendering.</P>
